# Jero's Personal Website

A personal website I built while learning HTML and CSS.

## What it is

This is my first public web development project.

I wanted to make something that felt more personal than a basic beginner HTML page, so I built the site around a space theme. I made the layout, styling, navigation, backgrounds, and different sections myself using HTML and CSS.

The site includes:

- A navigation bar
- About Me and Interests sections
- A Projects section
- A Contact section linking to my GitHub

## Built with

- HTML
- CSS

No JavaScript is used in this project.

## Running it locally

You don't need to install anything.

1. Clone the repository.
2. Open `index.html` in a browser.

Or use VS Code with Live Server if you have it installed.

## What I learned

This project helped me get more comfortable with the basics of HTML and CSS, especially:

- Structuring a webpage with HTML
- Using classes and IDs
- Creating layouts with Flexbox
- Styling elements with CSS
- Working with spacing, borders, and rounded corners
- Creating backgrounds and visual effects
- Linking different parts of a webpage with navigation

I'm still new to web development, so this project is mainly a starting point for me. I want to use what I learned here in future projects.
